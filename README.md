# Is the Sun Conscious?

**Live:** https://aicoderdhruv.github.io/is-the-sun-conscious/

Heliomind is an immersive, scroll-driven 3D journey through Rupert Sheldrake's essay *"Is the Sun Conscious?"* (Journal of Consciousness Studies, 28(3–4), 2021, pp. 8–28). It moves from the Sun's plasma surface out to the Milky Way, one scale per chapter.

Built with Three.js (custom GLSL shaders), GSAP ScrollTrigger and Lenis smooth scroll, all in a single `index.html` with libraries loaded from CDN. It works on desktop and mobile.

Field lines, granulation and orbits are illustrative and not to scale.
